Лабораторная работа 1: Очередь и Стек
Цель работы
Необходимо реализовать две базовые структуры данных Queue и Stack. Не забываем про типизацию и Generic. Должно быть две реализации в ООП стиле и функциональном стиле!

Структуры данных

Stack (Стек)
- Принцип: LIFO (Last In, First Out) - последний пришел, первый ушел
- Основные операции:
  - push(item) - добавление элемента на вершину
  - pop() - удаление и возврат элемента с вершины
  - peek() - просмотр элемента на вершине без удаления
  - is_empty() - проверка на пустоту
  - size() - количество элементов

Queue (Очередь)
- Принцип: FIFO (First In, First Out) - первый пришел, первый ушел
- Основные операции:
  - enqueue(item) - добавление элемента в конец
  - dequeue() - удаление и возврат первого элемента
  - front() - просмотр первого элемента без удаления
  - is_empty() - проверка на пустоту
  - size() - количество элементов

Особенности реализаций

ООП-реализация
- Используются классы с методами
- Состояние хранится в атрибутах объектов
- Мутабельные структуры (изменяют состояние объекта)
- Более императивный подход

Функциональная реализация
- Используются чистые функции
- Структуры данных иммутабельны (неизменяемы)
- Каждая операция возвращает новую структуру
- Более декларативный подход
